# Легенды Калуги

Сайт городского проекта «Легенды Калуги».

## Устройство

- `docs/` — статический интерфейс для GitHub Pages;
- `app/api/entries/` — внешний API и общее хранилище записей;
- `public/` — исходные медиафайлы.

GitHub Pages обращается к API на Sites-хостинге, поэтому посетители видят одни и те же записи и могут редактировать их по ссылке.

## Разработка

```bash
npm install
npm run dev
npm run build
```
